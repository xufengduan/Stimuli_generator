Advanced parameters

Add a parameter name, choose its value type, and enter a value. The form builds the JSON automatically.

  • Number: Numeric values, such as 2000 or 0.7.
  • Text: A string value, without surrounding quotes.

Stimulus Design

Provide example items and describe what you want to generate.

i

Example stimuli

Add a complete example for each condition on the left. On the right, optionally list elements that must be unique across items, with their values in each example.

Each item is edited independently, including names, values and row order. Use the row handles to reorder within an item, or focus a handle and press the up/down arrow keys.

Use the copy button to duplicate an item, or Add item for a new blank example.

Add example items to show the agent what to generate for each experimental condition, and specify duplication constraints for the elements used in each item.

i

Stimulus design

Describe the research question, the structure of each stimulus item, and the requirements for each experimental condition.

Include:

  • Components: What each item should contain.
  • Conditions: How the content should differ across conditions.
  • Constraints: What to include, what to avoid, and which components must be unique across items.
  • Controls: Which properties should be matched across conditions, such as length or complexity.

Replace the bracketed fields in the default template with your experiment's details.

Example

Generate an active sentence and a passive sentence for each verb and name. Keep the verb and name unique across items, and match the two conditions for meaning and plausibility.

Agent Property Settings

Set the criteria for validation and the dimensions for scoring.

i

Validator

The Validator checks the mandatory requirements that every generated stimulus must meet. An item is accepted only when all criteria pass.

How to configure it

  1. Enter a short criterion name in Properties.
  2. Explain the requirement in Description.
  3. Write each requirement so that a valid item returns true.

Example

Properties Description
SameMeaning The active and passive sentences convey the same meaning.
ContainsName Both sentences contain the specified name.

Define the property name (left) and its validation logic (right). Help the Validator agent to filter out unacceptable items.

Properties Description Action
i

Individual criteria validation

When enabled:

  • The Validator checks each criterion in a separate API call.
  • Validation stops as soon as a criterion fails.
  • More focused checks may require additional API calls and processing time.

When disabled, all criteria are checked together.

i

Scorer

The Scorer assigns numeric ratings to each generated item so that you can compare, filter, or rank results.

Define:

  • Aspects: The dimension to evaluate.
  • Description: What the rating measures.
  • Min score / Max score: The allowed scoring range.

Example

Aspects Description Min score Max score
Fluency How natural and grammatical the sentences are. 0 10
Plausibility How realistic the described events are. 0 10

Define the dimensions along which the generated items will be rated.

Aspects Description Min score Max score Action
i

Individual aspect scoring

When enabled, the Scorer evaluates each aspect in a separate API call. This provides a more focused evaluation, but may increase the number of API calls and processing time.

When disabled, all aspects are scored together.
